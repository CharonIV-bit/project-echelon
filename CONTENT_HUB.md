# Content Hub policy

Project Echelon plans to include a built-in Content Hub for shaders and resource packs. Players will be able to choose compatible content and install it into their selected Minecraft profile with one click.

## A curated catalogue

The Content Hub will be maintained by the Project Echelon team. It will not accept direct public uploads and will not operate as an unmoderated community marketplace.

Before a listing is published, the Project Echelon team will review:

- The original creator and download source
- The license or permission to redistribute the content
- The supported Minecraft versions and required shader loader
- The archive structure and the files included in it
- Whether the content conflicts with Project Echelon's fair-play rules

Approved listings will display the original creator, source, supported versions, and a **Project Echelon Verified** label.

## What the hub installs

The hub will be limited to shader packs and resource packs. It will place the selected archive in the appropriate folder for the chosen Minecraft profile and keep a local record so the player can update or remove it later.

The hub will not install executable programs, standalone installers, cheat modules, or unknown mod files. It will not silently add content; every installation must be started by the user.

## Fair-play review

Visual customization does not automatically make a pack suitable for Echelon. Content intended to reveal hidden blocks or entities, remove visibility limitations for an advantage, or otherwise conflict with the project's fair-play rules will not be listed.

## Creator rights

Project Echelon will respect the rights of shader and resource-pack creators. Content will only be mirrored or packaged when its license or the creator's permission allows it. When redistribution is not permitted, the hub must use an approved official source rather than re-uploading the creator's work.
